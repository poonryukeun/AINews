## 主题速览

### 大模型

<a id="openai-gpt-55"></a>
#### OpenAI 发布 GPT‑5.5（并更新至 API）
摘要：OpenAI 介绍 GPT‑5.5 作为面向“真实工作”的新一代模型，强调在编程、研究、数据分析与跨工具执行任务上的改进，并提到更强的安全评估与防护。页面更新说明 GPT‑5.5 与 GPT‑5.5 Pro 已进入 API。  
关键点：
- 更强调 agentic coding 与长流程任务的“持续执行/自我校验”。  
- 官方给出多项基准（如 Terminal-Bench、OSWorld 等）对比。  
- 提到更强的安全评估、红队与防护配置。  
来源：
- [Introducing GPT‑5.5](https://openai.com/index/introducing-gpt-5-5/)

<a id="openai-gpt-54"></a>
#### OpenAI 发布 GPT‑5.4（强调计算机使用、工具搜索与 1M 上下文）
摘要：OpenAI 介绍 GPT‑5.4 作为面向专业任务的前沿模型，强调原生计算机使用能力、工具搜索（Tool search）机制，以及在文档/表格/演示等工作负载上的改进。  
关键点：
- 支持“工具搜索”，减少把全部工具定义塞进上下文带来的 token 负担。  
- 强调计算机使用与视觉能力提升，并给出 OSWorld 等评测。  
- API 中提供 `gpt-5.4` / `gpt-5.4-pro`。  
来源：
- [Introducing GPT‑5.4](https://openai.com/index/introducing-gpt-5-4/)

<a id="anthropic-opus-47"></a>
#### Anthropic 发布 Claude Opus 4.7
摘要：Anthropic 宣布 Opus 4.7 正式可用，强调在复杂、长时间的软件工程任务上更稳定、更一致，同时提到更好的视觉能力与更“有审美”的专业输出。并说明将网络安全防护先落在 Opus 4.7 等模型上进行真实部署验证。  
关键点：
- 强调长任务的严谨性、指令遵循与自我验证。  
- 提到网络安全相关的自动检测与阻断机制、以及 Cyber Verification Program。  
- 覆盖 Claude 产品与 API，以及多云分发渠道。  
来源：
- [Introducing Claude Opus 4.7](https://www.anthropic.com/news/claude-opus-4-7)

### 安全与对齐

<a id="openai-privacy-filter"></a>
#### OpenAI 发布 OpenAI Privacy Filter（开源权重 PII 识别与脱敏）
摘要：OpenAI 发布 Privacy Filter，定位为可本地运行的 PII 检测与脱敏模型，用于高吞吐隐私工作流，并提供模型结构、标签体系与评测信息。  
关键点：
- 强调可本地运行，减少未脱敏数据外发风险。  
- 提供标签体系（如 private_email、account_number、secret 等）。  
- 提到在 PII-Masking-300k 等评测上的表现与限制说明。  
来源：
- [Introducing OpenAI Privacy Filter](https://openai.com/index/introducing-openai-privacy-filter/)
